# 保有株シミュレーター

保有銘柄の株価が動いたときの評価損益を試算する、個人用のPWA（ホーム画面に追加して使うWebアプリ）です。
ビルド不要の静的ファイルのみで動きます。

公開URL: `https://goldzhiro.github.io/stock-sim/`

## できること

- 保有銘柄（銘柄名・コード・株数・取得単価・現在株価）の登録／編集／削除
- ポートフォリオ全体の評価額・取得額・評価損益・損益率の合計
- **銘柄ごとの個別調整** — カードをタップして、想定株価／変動率／目標評価損益の
  いずれかを入力すると、その銘柄だけ動かせます。合計は常に各銘柄の想定株価から
  計算されるため、「A社は+30%、B社は-10%」といった混在状態も試せます
- 全銘柄への一律適用（スライダー／数値入力／プリセット）
- **逆算**
  - ポートフォリオ全体：目標の評価損益（例：+50万円）や目標評価額 → 必要な変動率
    （結果は全銘柄へ一律に適用されます）
  - 銘柄ごと：目標の評価損益 → 必要な株価と変動率。損益ゼロになる株価も表示

個別に調整している間はシミュレーションカードに「銘柄ごとに個別調整中です
（全体では -2.84%）」と表示され、そこから全銘柄を現在値に戻せます。
サマリーの変動率は各銘柄の評価額で加重平均した全体の変動率です。
- 端末内（localStorage）に自動保存。JSONでバックアップ／復元
- Service Workerによりオフラインでも起動

株価は自動取得せず手入力です。証券アプリの現在値を見て更新してください。

## iPhoneへのインストール

1. Safariで `https://goldzhiro.github.io/stock-sim/` を開く
2. 共有ボタン → 「ホーム画面に追加」
3. ホーム画面のアイコンから起動（アドレスバーなしの全画面で動きます）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | スタイル（ダーク／ライト自動切替） |
| `app.js` | 状態管理・計算・保存 |
| `sw.js` | オフライン用キャッシュ |
| `manifest.webmanifest` | ホーム画面追加時の設定 |
| `icons/` | アプリアイコン |

`app.js` などを更新したときは、`sw.js` の `CACHE` の版数（`stock-sim-v1`）を上げると
古いキャッシュが確実に置き換わります。

## 注意

このリポジトリはHexoの生成物を配置する構成のため、`hexo deploy` で全体を上書きすると
このディレクトリが消える可能性があります。ブログ側を再デプロイする運用に戻す場合は、
Hexoの `source/stock-sim/` にこのディレクトリを置くなどして生成対象に含めてください。

## データの保存場所

データはブラウザのlocalStorage（キー `stock-sim.v1`）にのみ保存され、外部には一切送信されません。
Safariの履歴削除や機種変更で消えるため、「データ」画面からJSONを控えておいてください。
